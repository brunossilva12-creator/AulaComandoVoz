<a name="português"></a>
## 🇧🇷 Português

Um **Assistente Virtual interativo** com suporte a texto e comandos de voz, desenvolvido com o auxílio de Inteligência Artificial Generativa. O usuário pode digitar perguntas, usar o microfone para falar diretamente com o bot e ouvir as respostas em áudio.

🔗 **Acesse o projeto online:** [brunossilva12-creator.github.io/AulaComandoVoz](https://brunossilva12-creator.github.io/AulaComandoVoz/)

### ✨ Funcionalidades
- **Interação por Texto e Voz:** Permite enviar mensagens digitando no campo de texto ou falando diretamente pelo microfone (`🎙`).
- **Respostas em Áudio (Text-to-Speech):** O assistente converte as respostas em fala, tornando a conversa mais acessível e dinâmica.
- **Sugestões Rápidas de Perguntas:** Botões interativos divididos por temas (*Apresentação, Assistente Virtual, Inteligência Artificial, Comando de Voz, Resposta em Áudio e Funcionamento*) para iniciar a conversa com um clique.
- **Indicador de Status e Interface Moderna:** Visual limpo em estilo mensageiro, com status *Online* e layout responsivo.

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da interface do chat e controles de áudio.
- **CSS3:** Estilização moderna, balões de diálogo, cartões de sugestão e responsividade.
- **JavaScript (Web Speech API):** Lógica do chatbot, captura de áudio pelo microfone (*SpeechRecognition*) e leitura de respostas em voz alta (*SpeechSynthesis*).
- **IA Generativa:** Apoio na estruturação do código, lógica de respostas e design da interface.

### 🚀 Como executar localmente
1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Abra a pasta do projeto e execute o arquivo `index.html` em um navegador compatível com recursos de voz (como Google Chrome ou Microsoft Edge).

<a name="english"></a>
## 🇺🇸 English

An interactive **Virtual Assistant** supporting both text and voice commands, developed with the assistance of Generative AI. Users can type questions, use their microphone to speak directly to the bot, and listen to audio responses.

🔗 **Live Demo:** [brunossilva12-creator.github.io/AulaComandoVoz](https://brunossilva12-creator.github.io/AulaComandoVoz/)

### ✨ Features
- **Text & Voice Interaction:** Send messages by typing or speaking directly through the microphone (`🎙`).
- **Audio Responses (Text-to-Speech):** The assistant reads responses aloud for a more dynamic and accessible experience.
- **Quick Question Prompts:** Interactive topic buttons (*Introduction, Virtual Assistant, Artificial Intelligence, Voice Commands, Audio Response, and How It Works*) to start chatting with a single click.
- **Status Indicator & Modern UI:** Clean messenger-style layout with an *Online* badge and responsive design.

### 🛠️ Technologies Used
- **HTML5:** Semantic structure of the chat interface and audio controls.
- **CSS3:** Modern styling, message bubbles, prompt cards, and responsiveness.
- **JavaScript (Web Speech API):** Chatbot logic, microphone voice capture (*SpeechRecognition*), and spoken output (*SpeechSynthesis*).
- **Generative AI:** Assisted code structuring, response logic, and UI design.

### 🚀 How to run locally
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Open the project folder and launch the `index.html` file in a speech-compatible browser (such as Google Chrome or Microsoft Edge).
